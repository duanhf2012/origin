# 合约、生成与 Bind

共享教程合约 [`examples/_support/tutorialrpc/player.go`](../../_support/tutorialrpc/player.go) 中的 `PlayerRPC` 通过 `//origin:rpc` 标记。生成代码已经提交，因此可以直接运行：

```text
run.bat
```

也可以重新生成并检查差异：

```text
generate.bat
```

预期日志：`rpc result: player-1001`。

对应教程：[RPC 基础](../../../docs/baseline/v3.0/guides/05-rpc-basics.md)。
