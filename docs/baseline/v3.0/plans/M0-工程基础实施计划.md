# Origin 第三版 M0 工程基础实施计划

> 计划状态：已完成
> 创建日期：2026-07-25
> 对应里程碑：[M0 工程基础里程碑设计](../design/milestones/M0-工程基础里程碑设计.md)

## 1. 实施目标

只建立 Go module、构建信息和基础错误包，不实现 M1 及后续能力。

## 2. 实施步骤

1. 创建 `go.mod`，module 为 `github.com/duanhf2012/origin/v3`，最低 Go 版本为 1.26.5。
2. 创建公开 `buildinfo` 包：
   - 内部保存 BuildTime、Version、Commit；
   - 提供只读函数；
   - 验证空值和 `-ldflags -X` 注入。
3. 创建公开 `errs` 包：
   - 定义 `uint32 Code` 和首批通用错误码；
   - 实现标准文本、固定哨兵、`CodeOf`、`IsCode`、`New`、`NewMessage` 和 `Wrap`；
   - 支持 Context 映射以及 `errors.Is`、`errors.As`、`Unwrap`。
4. 补充单元测试和固定错误分配 Benchmark。
5. 执行格式化、静态检查、测试、竞态检测和 Benchmark。
6. 在 `scripts` 增加 `buildwin.bat` 和 `buildlinux.bat`，验证 Windows 与 Linux amd64 编译。
7. 在 `examples/_baseline/v3.0/m0-basic` 保留最小可运行示例。
8. 将实际命令与验收结果写回本计划。

## 3. 不进入本次实施

- 日志；
- Buffer 池；
- 配置文件；
- 命令与 PID；
- TCP、NATS；
- Application、Node、Service；
- Await、Timer；
- Protobuf、代码生成和 RPC。

## 4. 验证命令

```text
gofmt
go vet ./...
go test ./...
go test -race ./...
go test -run=^$ -bench=. -benchmem ./...
scripts\buildwin.bat
scripts\buildlinux.bat
```

构建脚本使用示例：

```text
scripts\buildwin.bat
scripts\buildlinux.bat
scripts\buildwin.bat ./examples/_baseline/v3.0/m0-basic
scripts\buildlinux.bat ./examples/_baseline/v3.0/m0-basic
```

无参数调用只编译并校验全部包，不生成服务器二进制文件。指定 `./examples/_baseline/v3.0/m0-basic` 后，默认生成 `m0-basic.exe` 或 `m0-basic`；也可以通过参数传入 `-o` 自定义输出文件。

## 5. 验收记录

验收日期：2026-07-25。

已完成：

1. 使用 Go 1.26.5 建立 `github.com/duanhf2012/origin/v3` module。
2. `buildinfo` 默认保持空值，并通过测试子进程执行 `go test -ldflags -X`，验证 BuildTime、Version、Commit 的真实链接注入；不额外创建测试用 `main` 包。
3. `errs` 已实现首批稳定错误码、固定哨兵、动态消息、本地 cause、Context 映射以及 `errors.Is`、`errors.As`、`Unwrap`。
4. M0 未引入任何第三方 Go module，也未提前实现 M1 及后续能力。
5. `scripts` 下的 `buildwin.bat` 和 `buildlinux.bat` 默认编译全部包，也支持把命令行参数作为指定构建目标；脚本自动注入带本地时区的 BuildTime、当前提交上的精确 Git Tag 和 Commit。可以分别使用 `ORIGIN_BUILD_TIME`、`ORIGIN_BUILD_VERSION`、`ORIGIN_BUILD_COMMIT` 覆盖自动值。
6. `examples/_baseline/v3.0/m0-basic` 提供构建信息和基础错误码的最小使用示例，并跟随根模块参与构建。
7. 以下检查均通过：

```text
go version
go vet ./...
go test ./...
go test -race ./...
go test -run=^$ -bench=. -benchmem ./...
scripts\buildwin.bat
scripts\buildlinux.bat
```

验证环境：

