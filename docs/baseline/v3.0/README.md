# Origin v3.0 文档

使用者请从仓库根目录的 [README](../../../README.md) 开始，或直接阅读 [v3.0 使用指南](./guides/README.md)。

本目录同时保留 Origin v3.0 从 M0 到 M22 的设计、实施和验收基线：

- [使用指南](./guides/README.md)：面向业务开发和运维的教程、示例与参考资料。
- [设计索引](./design/设计文档索引.md)：架构详细设计与 M0--M22 交付边界。
- `plans/`：实施范围、验证命令和验收结果。
- `migration/`：v2 到 v3 的功能迁移矩阵。
- `../../examples/_baseline/v3.0/`：M0、M7 等历史验收样例；当前使用者教程不依赖这些目录。

后续能力变更、行为调整和对应使用文档进入 [maintenance/v3.0](../../maintenance/v3.0/README.md) 或更高版本维护目录；本目录记录 v3.0 已发布能力的基线使用方式。
