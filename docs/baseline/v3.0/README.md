# Origin v3.0 文档基线

本目录保存 Origin v3.0 从 M0 到 M22 的完整设计、实施和验收记录，已经完成并冻结。

- [设计索引](./design/设计文档索引.md)：架构详细设计与 M0--M22 交付边界。
- `plans/`：实施范围、验证命令和验收结果。
- `migration/`：v2 到 v3 的功能迁移矩阵。

本目录只允许修复事实性错误、链接或排版问题；v3.0 发布后的维护改动进入 [maintenance/v3.0](../../maintenance/v3.0/README.md)，任何新增能力、行为调整和使用者文档进入相应的后续维护版本目录。
