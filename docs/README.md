# Origin 文档入口

文档按目标发布版本隔离。请先进入对应版本目录；不要把后续维护内容追加到已冻结版本。

| 版本 | 目录 | 状态 | 使用方式 |
| --- | --- | --- | --- |
| v3.0 | [v3.0/](./v3.0/README.md) | 已完成、冻结 | 架构基线、实现过程、验收和迁移事实；仅允许勘误或修复失效链接。 |
| v3.1 | [v3.1/](./v3.1/README.md) | 预留 | v3.1 的设计、计划、变更记录、报告和使用指南。 |
| v3.2 | [v3.2/](./v3.2/README.md) | 预留 | v3.2 的独立文档空间。 |

## 维护规则

1. 新需求先写入目标版本的 `design/`；未确认方案放入 `proposals/`。
2. 设计确认后才创建 `plans/`；实现完成后写入 `changes/` 和必要的 `reports/`。
3. 面向使用者的内容统一放入目标版本的 `guides/`，不与内部设计混放。
4. 每篇维护文档开头注明状态、目标版本、兼容性和依赖基线。例如：`基线：v3.0`、`目标：v3.1.0`。
5. 一个版本发布后冻结其目录；下一轮开发进入下一个版本目录，不回填新的功能设计。
