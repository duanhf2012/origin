## 4. 功能、测试与覆盖

正式使用者外观由编译契约锁定：Application、Service/Module、Command、Config、Log、Admin、
Discovery Provider SPI、Diagnostics 和生成 RPC Client。`node.New`、`rpc.Runtime/Reader/Writer/Sizer`
等导出项被明确归类为框架集成层，不作为普通教程外观。

最终原始全仓语句覆盖率为 `72.6%`；该数字包含大量独立 Example，不作为单一发布指标。合并七组
单元和真实集成 Profile 后审计 `1,672` 个生产函数，跨平台剩余 `15` 个零覆盖函数，均是无操作
接口、第三方罕见回调、不可达低层分支或不可稳定注入的内部防御，没有未知重点路径。详细分类见
[Origin 覆盖率、Example 与教程最终验收报告](./Origin覆盖率Example与教程最终验收报告.md)。

服务自己调用自己的 RPC 最终覆盖：

- 普通 goroutine 中同步 `Call`；
- Service Task 内 `Await`、`Async`、`Notify` 和 FIFO 回调；
- 调用完成后执行槽继续工作、回调恰好一次；
- Task 内同步 `Call` 占住唯一执行槽时，只能由 Deadline 有界退出的死锁边界；
- Windows、Ubuntu 均重新执行 Race `count=100`，全部通过。

## 5. 系统、性能与安全

Ubuntu 系统级验收完成 24 场景 × 3 轮的正式 M22 矩阵，共 72 条结果，所有
`errors/timeouts/pending_end` 为零；没有场景超过 `-25%` 阻断线。64 Node × 64 Service 的
Diagnostics Summary 与 Full、过载、恢复风暴、长稳、日志/Admin/pprof 共存均取得稳定结论。
完整数据见
[Origin 系统级稳定性、容量与性能验收报告](./Origin系统级稳定性容量与性能验收报告.md)。

独立终审再次执行 24 场景短矩阵和三组 3 秒公开 Benchmark。Ubuntu 当前结果为 Local Await
`6075 ns/op`、TCP 32B `39120 ns/op`、NATS 32B `74562 ns/op`，与同环境既有基线一致，没有
未解释退化。短矩阵和可观测性共存 Race 在 Windows、Ubuntu 均通过。

Task 6 已在升级 `klauspost/compress v1.18.7` 后确认 `govulncheck` 可达漏洞为零，并完成许可证
禁用检查；此后没有依赖或生产行为变化，仅新增测试、文档、无引用私有函数删除和机械格式化，
安全结论仍有效。
