# Origin v3.1 文档

此目录预留给 v3.1 的持续维护与新能力开发。它以 `../../baseline/v3.0/` 为初始基线；首个维护项开始时，按需建立以下子目录：

- `proposals/`：尚未确认的方案。
- `design/`：已确认的设计与兼容性约束。
- `plans/`：已确认设计的实施计划。
- `changes/`：已完成变更的摘要、关联提交与验证结果。
- `reports/`：性能、故障演练、兼容性和验收报告。
- `guides/`：面向使用者的使用、部署、配置和排障文档。

每篇文档必须注明：状态、目标版本、兼容性和基线（通常为 `v3.0`）。
